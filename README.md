# Java Tasks

A collection of Java exercises and small application projects. This repository contains multiple independent tasks rather than one application with a single root build.

## Where to start

- [Java Streams examples](streams/README.md) — small examples organized by operation, with supporting `Employee` and `Student` classes.
- [Spring and Hibernate tasks](src/) — exercises and projects grouped into directories such as `EWalletSystem`, `HibernateTasksLectures4To6`, `TasteHub`, and `VehicleRegistrationSystem`.
- [Database tasks](src/DB%20TASKS/) — SQL and database exercises.

Each folder may have its own setup and dependencies. Open the relevant project directory and follow its local files; there is no shared Maven wrapper or build file at the repository root.

## Notes

This is a learning archive. For a finished backend project, see the separate [Fraud Detection System](https://github.com/Dina-Elmowafy/Fraud-Detection-System), [E-Wallet System API](https://github.com/Dina-Elmowafy/Ewallet-System-SpringBoot-API), and [Retivio Smart Library API](https://github.com/Dina-Elmowafy/Retivio-Smart-Library-API) repositories.
